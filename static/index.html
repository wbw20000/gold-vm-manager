A CLEAN START

新建 VM

支持中文、字母、数字、空格、短横线、下划线；不能覆盖其他 VM。

磁盘容量无效：请输入 30–1024 GiB 范围内的整数。

30–1024 GiB，填整数，默认 50 GiB。较小的磁盘可能放不下 macOS 或后续系统更新。默认 2 vCPU／4 GiB，可手动调整。镜像最低要求不满足时会拒绝，不会偷偷增加资源。2 核可能较慢或有稳定性风险。

只安装 macOS 到新暂存盘。恢复后停止，不预装软件、不读取宿主代理，也不会创建可启动的 VM。

从零安装：新磁盘、NVRAM、ECID 与 MAC；硬件型号受 Apple 限制，不承诺全部硬件字段不同。安装阶段无网卡，完成后仅通过专属端点防护联网。

原型功能：创建、重建、删除和启动已在开发环境通过面板验证，不代表完整自动初始化或任意环境兼容。首次设置与软件安装仍需手动完成。失败可能保留暂存文件；请先备份重要数据。

不可撤销：旧 VM 内的内容将全部丢弃

确认后会先准备镜像和新系统，再删除旧磁盘及暂停状态，不保留旧 VM 备份。宿主共享原文件不会删除，但新 VM 的共享配置会清空。远端 token 不会因此撤销，宿主备份也不会自动擦除。

扩容磁盘

30–1024 GiB，填整数。填写扩容后的总容量，不是增量；只能扩大。

建议先备份这台 VM。此操作仅扩大虚拟磁盘，不会自动开机，不在宿主机挂载或格式化磁盘。若客机未显示新增空间，可能还需在客机内扩展 GPT 分区和 APFS 容器。

永久删除 VM

不可撤销：永久删除选中 VM 的磁盘、配置与暂停状态，不提供撤销或备份。不会删除宿主共享目录原文件；不会撤销远端令牌或清除宿主备份。运行中的 VM 必须先正常关机；本操作不会自动关机或强制停止。

自动初始化 · 预览

预览：当前宿主 macOS 26 的客机 UI 自动化尚未完成真实端到端验收。遇到未知页面必须停止，不猜测点击；启动请求不代表初始化完成。已有账号或恢复模式不适用。

用户名、全名和密码仅在原生 App 的安全表单内填写，不会进入网页、模型或此请求。此页面只提交非敏感初始化模板；不会自动使用 Apple Account。
